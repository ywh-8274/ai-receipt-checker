영수증 OCR 신뢰도 임계값 비교

실행일: 2026-11-24 · Windows CPU · Python 3.12 · PaddlePaddle 3.2.0 · PaddleOCR 3.3.2

같은 samples.csv 12건을 각각 실제 실행했습니다. 기본값 0.85와 0.97을 비교하며, 노란 행은 판정이 바뀐 샘플입니다.

1. 실행 조건

cd C:\ai_receipt
$env:USERPROFILE = 'C:\ai_receipt\.runtime'
python main.py --csv samples.csv
python main.py --csv samples.csv --threshold 0.97

임계값은 OCR 모델의 인식값을 바꾸는 옵션이 아니라 총액 신뢰도 판정과 글자 박스 색상에 적용됩니다. 신뢰도가 기준 미만이면 담당자 확인, 박스는 빨간색입니다. 승인번호 누락 판정은 신뢰도 검사보다 우선합니다.

4. 변경 사유

S03: 정상 → 담당자 확인

0.85: 승인번호 확인: SIM-0004 / 검산 통과: 25,800 + 1,000 = 26,800 / 승인금액 26,800 = 증빙금액 26,800

0.97: 총액 '26,800' 신뢰도 0.968429 < 기준 0.97

S11은 총액 신뢰도가 0.97 미만이어도 승인번호가 없어 두 실행 모두 ‘추가 증빙 필요’입니다.

5. 재현 및 해석

두 실행의 샘플별 OCR 원본 JSON 완전 일치: 12/12. 임계값 상승으로 정상 영수증도 수동 검토 대상이 될 수 있으며, 이 12개 샘플의 결과를 일반적인 정확도로 해석할 수는 없습니다.
